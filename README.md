# Social Discovery App

A legacy PHP social discovery application, shared as a historical code sample. The original project describes itself as a Badoo / Hot-or-Not style clone.

## Repository structure

The source includes the application, administrator area, themes, plugins, install files, and mobile-related folders.

## Status and setup

This is an older code snapshot. The original setup note refers to WAMP and an `/install` route, but that process has not been revalidated. Review the code in an isolated environment before running or deploying it. No live service or production readiness is claimed.
